# CS207 2026 Fall Project — 基于 EGO1 的数字华容道

3x3 数字华容道数字游戏机，面向 EGO1（XC7A35T-1CSG324C）开发板。
本目录是 Vivado 工程 `proj.xpr` 的源码部分，已实现课程 PDF 的全部基础功能，
并额外提供 VGA 二维棋盘作为高级外设输出。

## 1. 已实现功能与评分项对照

| PDF 要求 | 分值 | 实现情况 |
|---|---|---|
| 复位、棋盘初始化 | 10 | 复位清空全部状态；9 次拨码输入 + S0 确认；0-8 去重与范围检查 |
| 棋子移动、合法性判定、步数统计及二进制展示 | 25 | 空白格上下左右判定；有效/无效计数；8 个 LED 二进制展示 |
| 辅助提示 | 10 | 8 个 LED 对应 1-8 号棋子，S1 切换提示/统计 |
| 通关判定、十进制步数展示 | 10 | 棋盘等于 `123456780` 判定；通关后 S0 在数码管显示有效/无效步数十进制 |
| 撤回 | 5 | S4 撤回，深度 16，棋盘与计数同步恢复（含无效步） |
| 演示模式 | 10 | S2 进入，S3 单步；硬编码 `123456708 -> 非法移动 1 -> 合法移动 8 -> 通关 -> 统计 -> 复位` |
| 高级外设（可选） | — | VGA 640x480 二维棋盘，K6 指示灯常亮表示高级外设使用中 |

## 2. 操作说明

### 按键（EGO1 通用按键，按下为高电平）

| 按键 | 引脚 | 功能 |
|---|---|---|
| S0 | R11 | 确认：初始化每个棋子 / 游戏中移动 / 通关后查看统计 |
| S1 | R17 | 展示切换：游戏提示（奇数次）↔ 步数统计（偶数次） |
| S2 | R15 | 模式切换：游戏模式 ↔ 演示模式 |
| S3 | V1 | 演示模式单步推进（仅演示模式有效） |
| S4 | U4 | 撤回（仅游戏模式有效） |
| S6 | P15 | 复位（低电平有效，板上有 4.7K 上拉） |

### 拨码开关

使用**最左侧 4 个滑动拨码开关**（SW0-SW3），`SW0` 为最高位：

```
SW0 SW1 SW2 SW3   输入值
 0   0   0   1      1
 1   0   0   0      8
 0   0   0   0      0（空位）
```

- 初始化时按二维棋盘从左到右、从上到下的顺序，逐个输入棋子编号并按 S0。
- 输入 9-15 或重复编号均为非法输入，当前位保持待输入状态。
- 9 个棋子全部输入后自动进入游戏。

### LED 含义（从左到右，均高电平点亮）

| LED | 引脚 | 含义 |
|---|---|---|
| D0-D7 | F6,G4,G3,J4,H4,J3,J2,K2 | 提示页：对应 1-8 号棋子是否可移动；统计页：左 4 位有效步数，右 4 位无效步数（二进制） |
| D8-D11 | K1,H6,H5,J5 | 第 9 个棋格棋子编号的 4 位二进制，K1 为最高位 |
| D12 | K6 | 高级外设（VGA）使用中，常亮 |
| D13 | L1 | 游戏模式（初始化与游戏中亮） |
| D14 | M1 | 演示模式 |
| D15 | K3 | 游戏状态：闪烁 = 非法输入；长亮 = 通关；熄灭 = 其他 |

> 4 个步数 LED 只能表示 0-15，因此有效/无效步数在 15 处饱和，
> 数码管十进制也显示 `15`，保证“数码管数值与 LED 二进制一致”。

### 数码管

- 正常：最左 8 位显示棋盘第 1-8 格；第 9 格由 D8-D11 显示。
- 某格为 0 号棋子：该位数码管熄灭；第 9 格为 0 时 4 个 LED 全灭。
- 初始化非法输入：该位显示 `E`；若第 9 位非法，D8-D11 全亮。
- 通关后按 S0：最左两位显示有效步数十进制，最右两位显示无效步数十进制，中间四位熄灭。
  再次按 S0 返回棋盘显示。

### 演示模式

S2 进入演示模式（M1 亮，立即显示第 1 步初始化棋盘 `123456708`）。之后每按一次 S3：

| 步 | 内容 | 输出 |
|---|---|---|
| 1 | 初始化 `123456708`（进入演示即显示） | 数码管 `1234567`，D8-D11=8，提示 5/7/8 |
| 2 | 模拟移动 1 号（非法） | 棋盘不变，无效步数=1，K3 闪烁 |
| 3 | 模拟移动 8 号（合法） | 数码管 `12345678`，D8-D11=0，有效=1/无效=1，K3 长亮 |
| 4 | 通关统计页 | 数码管 `01 ... 01` |
| 5 | 模拟复位 | 全部游戏输出清空 |
| 1 | 再按 S3 回到第 1 步 | 演示循环 |

S1 在演示模式中同样可以切换 LED 提示/统计页。

## 4. 上板步骤

1. 用 Vivado（2018.3 或更新）打开 `proj.xpr`，源码与约束已经加入工程。
   如果文件路径变动，可在 Tcl Console 执行 `source scripts/add_sources.tcl` 重新加入。
2. 确认顶层为 `top`，综合、实现、生成 bitstream。
   也可以直接执行：

   ```tcl
   source scripts/build.tcl
   ```

3. 连接 EGO1，打开硬件管理器，下载 `impl_1/top.bit`。
4. 按 S6 复位后开始操作。

如果不想在 GUI 中操作，也可以直接用命令行独立构建（不会动打开中的工程）：

```bash
"D:/software/vivado/2018.3/bin/vivado.bat" -mode batch -source scripts/build_batch.tcl
```

产物在仓库外的 `../build/proj_build.runs/impl_1/top.bit`，同时生成
`utilization.rpt` 与 `timing_summary.rpt`。

板子连接并上电后，可以直接下载：

```bash
"D:/software/vivado/2018.3/bin/vivado.bat" -mode batch -source scripts/program.tcl
```

## 6. 验收演示脚本（录视频可按此顺序）

1. 按 S6，确认数码管全灭、LED 全灭、L1 亮。
2. 依次输入 `1 2 3 4 5 6 7 0 8`（每输入一个按 S0），进入游戏。
3. 观察提示页：5/7/8 号 LED 亮（`00001011`）。
4. 输入 1 按 S0：K3 闪烁，按 S1 看到无效步数=1。
5. 输入 8 按 S0：数码管变 `12345678`，D8-D11 全灭，K3 长亮，通关。
6. 按 S0：数码管显示 `01 01`（左有效、右无效）。
7. 按 S4：棋盘回到 `123456708`，统计回到 0/1。
8. 按 S2 进演示，连续按 S3 走完 5 步。
9. 复位后重新初始化，故意重复输入一个数字，展示 `E` 与 K3 闪烁。

## 7. 设计说明与已知取舍

- **步数饱和**：4 个 LED 只能表示 0-15。为保证数码管十进制与 LED 二进制严格一致，
  计数在 15 饱和。若课程要求统计超过 15 步，需要增加 LED 位数或改变展示约定，
  请先与助教确认。
- **模式切换**：从演示模式切回游戏会回到“等待初始化”状态，避免把演示棋盘带入真实游戏。
- **撤回**：记录每次 S0 操作（包括无效移动）前的状态，深度 16；撤回后重新计算通关标志。
- **VGA**：使用 100 MHz 四分频得到 25 MHz 像素时钟（标准为 25.175 MHz），
  640x480@60 实测时序正确，绝大多数显示器可锁定。若不需要 VGA，可删除 `vga_board` 实例
  并把 `led_r[3]` 改为 0，其余功能不受影响。
- **引脚来源**：EGo1 用户手册 v1.1；课程 PDF 中的 LED 编号 D0-D15 与该手册一致。
  详见 `docs/ego1_pins.md`。
