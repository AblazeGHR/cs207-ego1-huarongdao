# EGO1 数字华容道：操作与引脚速查

## 1. 按键

| 按键 | FPGA 引脚 | 功能 | 什么时候用 |
|---|---|---|---|
| S0 | R11 | 确认 / 执行 | 初始化写当前格；游戏中移动棋子；通关后看统计；统计页再按返回棋盘 |
| S1 | R17 | 展示切换 | 提示页 ↔ 统计页，按一次切换一次 |
| S2 | R15 | 模式切换 | 游戏模式 ↔ 演示模式 |
| S3 | V1 | 演示单步 | 只在演示模式有效，按一次走一步 |
| S4 | U4 | 撤回 | 只在游戏模式有效，最多撤回 16 步 |
| S6 | P15 | 复位 | 低电平有效，按下清空棋盘/统计/状态 |
| S5 | — | PROG | 不要按，会擦除 FPGA 配置 |

## 2. 滑动拨码开关

板子丝印从右到左是 0-7，所以**最左边 4 个是 SW7-SW4**：

```
左                                                  右
SW7   SW6   SW5   SW4   |   SW3   SW2   SW1   SW0
P5    P4    P3    P2    |   R2    M4    N4    R1
 8     4     2     1    |        不用这 4 个
```

- **上 = 1，下 = 0**；
- SW7 是最高位，SW4 是最低位；
- 输入一个数字后按 S0，系统自动进入下一格。

### 输入 `123456708`

| 第几格 | 数字 | SW7 SW6 SW5 SW4 | 操作 |
|---|---|---|---|
| 1 左上 | 1 | 0 0 0 1 | 只拨 SW4 上，按 S0 |
| 2 中上 | 2 | 0 0 1 0 | 只拨 SW5 上，按 S0 |
| 3 右上 | 3 | 0 0 1 1 | SW5、SW4 上，按 S0 |
| 4 左中 | 4 | 0 1 0 0 | 只拨 SW6 上，按 S0 |
| 5 正中 | 5 | 0 1 0 1 | SW6、SW4 上，按 S0 |
| 6 右中 | 6 | 0 1 1 0 | SW6、SW5 上，按 S0 |
| 7 左下 | 7 | 0 1 1 1 | SW6、SW5、SW4 上，按 S0 |
| 8 中下 | 0 | 0 0 0 0 | 四个都拨下，按 S0 |
| 9 右下 | 8 | 1 0 0 0 | 只拨 SW7 上，按 S0 |

## 3. LED

### 物理顺序（从左到右）

```
D0  D1  D2  D3  D4  D5  D6  D7 | D8  D9  D10 D11 | D12 D13 D14 D15
F6  G4  G3  J4  H4  J3  J2  K2 | K1  H6  H5  J5  | K6  L1  M1  K3
```

### D0-D7：提示页 / 统计页复用

| LED | FPGA 引脚 | 提示页 | 统计页 |
|---|---|---|---|
| D0 | F6 | 1 号棋可移动 | 有效步数 bit3（MSB） |
| D1 | G4 | 2 号棋可移动 | 有效步数 bit2 |
| D2 | G3 | 3 号棋可移动 | 有效步数 bit1 |
| D3 | J4 | 4 号棋可移动 | 有效步数 bit0 |
| D4 | H4 | 5 号棋可移动 | 无效步数 bit3（MSB） |
| D5 | J3 | 6 号棋可移动 | 无效步数 bit2 |
| D6 | J2 | 7 号棋可移动 | 无效步数 bit1 |
| D7 | K2 | 8 号棋可移动 | 无效步数 bit0 |

- **提示页**：哪个灯亮，表示对应编号的棋子与 0 号空位相邻，可以移动。
- **统计页**：左边 4 个是有效步数，右边 4 个是无效步数；最左是最高位。
  例如无效步数 = 1 时，只有最右边的 `K2` 亮（`0001`）。

### D8-D15：第 9 格、模式与状态

| LED | FPGA 引脚 | 含义 |
|---|---|---|
| D8 | K1 | 第 9 格棋子编号 bit3（MSB） |
| D9 | H6 | 第 9 格 bit2 |
| D10 | H5 | 第 9 格 bit1 |
| D11 | J5 | 第 9 格 bit0 |
| D12 | K6 | 高级外设（UART）使用中，常亮 |
| D13 | L1 | 游戏模式（初始化或游戏中亮） |
| D14 | M1 | 演示模式 |
| D15 | K3 | 闪烁=非法输入；长亮=通关；熄灭=其他 |

### 常见状态一眼判断

| 状态 | D12 K6 | D13 L1 | D14 M1 | D15 K3 |
|---|---|---|---|---|
| 复位 / 初始化 | 亮 | 亮 | 灭 | 灭 |
| 游戏中 | 亮 | 亮 | 灭 | 正常灭，非法输入闪烁 |
| 通关 | 亮 | 亮 | 灭 | 长亮 |
| 演示第 1 步 | 亮 | 灭 | 亮 | 灭 |
| 演示第 2 步 | 亮 | 灭 | 亮 | 闪烁 |
| 演示第 3-4 步 | 亮 | 灭 | 亮 | 长亮 |
| 演示复位步 | 亮 | 灭 | 亮 | 灭 |

> 所有 LED 高电平点亮；复位后除 K6、L1 外，其余游戏 LED 全灭。

## 4. 数码管

- 正常页：最左 8 位显示棋盘第 1-8 格；第 9 格看 D8-D11。
- 空位 0：对应数码管熄灭；第 9 格为 0 时 D8-D11 全灭。
- 初始化非法：该位显示 `E`；第 9 位非法时 D8-D11 全亮。
- 统计页：左两位显示有效步数（十进制），右两位显示无效步数，中间四位熄灭。

## 5. 常用操作顺序

| 想做什么 | 操作 |
|---|---|
| 清空重来 | 按 S6 |
| 初始化 `123456708` | 按上表输入 9 个数字，每格按一次 S0 |
| 看提示 | 确认 S1 在提示页（左下 8 个 LED 对应 1-8 号棋） |
| 看步数 | 按 S1 切到统计页 |
| 非法移动 | 输入不与空位相邻的棋子，按 S0；K3 闪烁，无效步数 +1 |
| 通关 | 输入 8 按 S0，棋盘变 `12345678`，K3 长亮 |
| 看通关统计 | 通关后按 S0，数码管显示 `01 ... 01` |
| 撤回一步 | 按 S4；再按 S4 继续撤回 |
| 进入演示 | 按 S2，立即显示 `123456708` |
| 演示下一步 | 按 S3；依次为非法 1、合法 8、统计、复位、循环 |
| 退出演示 | 按 S2，回到等待初始化 |
| 串口看棋盘 | 电脑串口终端 COM 口 9600 8N1；每秒收到 3x3 ASCII |
